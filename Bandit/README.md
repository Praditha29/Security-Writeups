# OverTheWire - Bandit Writeups

Welcome to my **OverTheWire Bandit** writeup collection! This repository contains detailed walkthroughs and explanations for the Bandit wargame, organized level-wise to help beginners understand Linux fundamentals, command-line usage, and basic cybersecurity concepts.

## About Bandit

Bandit is a beginner-friendly Linux wargame created by **OverTheWire**. It is designed to teach essential Linux commands, file manipulation, permissions, networking, scripting, and problem-solving skills that form the foundation for penetration testing and cybersecurity.

**Official Website:** https://overthewire.org/wargames/bandit/

## Contents

| Levels | Topics Covered |
|---------|----------------|
| 0 – 5 | Linux basics, SSH, file reading, hidden files |
| 6 – 10 | Permissions, file search, strings, base64 |
| 11 – 15 | Hex, compression, SSH keys |
| 16 – 20 | Networking, ports, SSL, Netcat |
| 21 – 25 | Cron jobs, Bash scripting, automation |
| 26 – 30 | Git, shell escapes, privilege concepts |
| 31 – 34 | Advanced Linux concepts and final challenges |
